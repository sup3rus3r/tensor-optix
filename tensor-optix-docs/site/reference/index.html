API Reference

This section documents every public class and function in tensor-optix, organized by module. Docstrings are reproduced verbatim from source.

  • core - the framework-agnostic abstractions (BaseAgent, BasePipeline, BaseEvaluator, BaseOptimizer, LoopController/LoopCallback) plus shared utilities (checkpointing, normalizers, replay buffers, regime detection, ensembles).
  • Top-level API - RLOptimizer and the simplified Optimizer wrapper.
  • make_agent - the auto-selection factory.
  • Algorithms - the 15 built-in agents across PyTorch, TensorFlow, and JAX/Flax.
  • Pipelines - BatchPipeline, LivePipeline, VectorBatchPipeline.
  • Optimizers - SPSA, Momentum, Backoff, PBT, Adaptive (hyperparameter tuning).
  • Callbacks - Rich dashboard, Weights & Biases, TensorBoard.
  • Distributed - IMPALA-style async actor-learner with V-trace.
  • Trial search - TrialOrchestrator (Optuna-based).
  • Config / CLI - YAML config loading and the tensor-optix CLI.
  • ML mode - training arbitrary nn.Modules with the same loop.
  • Exploration - RNDPipeline (Random Network Distillation).
  • Neuroevo - the dynamic-topology policy subsystem.
