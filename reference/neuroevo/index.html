Neuroevo

pip install tensor-optix[neuroevo]

The neuroevo subsystem represents a policy as a mutable directed graph of heterogeneous scalar neurons with variable-delay edges, and evolves its topology live during training under statistical control.

  • NeuronGraph - the graph data structure: neurons, edges, Dale's Law, compiled/eager forward.
  • Neuron types - point, GRU, LSTM, trainable-GRU, trainable-LSTM.
  • Topology operations - the function-preserving primitives (insert, split, prune, merge) that all mutations are built from.
  • TopologyController - the LoopCallback that decides when to grow, prune, and merge.
  • GraphAgent - wraps a NeuronGraph as a BaseAgent with PPO-style learning; RecurrentGraphAgent adds truncated BPTT for trainable recurrent neurons.
  • BrainNetwork - composes multiple named NeuronGraph regions with sparse learnable inter-region pathways.
  • HebbianHook - local Oja-style weight updates alongside PPO gradients.
  • NeuromodulatorSignal - maps detected training regime to coordinated parameter changes across the stack.
  • TopologyAwareAdam - Adam variant that resets momentum state for parameters touched by a structural mutation.

See the Build a neuroevo agent guide for task-oriented usage.
